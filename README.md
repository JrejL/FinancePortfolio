# Finance portfolio · George Murad

Work samples in financial reporting, FP&A and data analysis, built the way the work runs on the job: data in a
database, SQL to shape it, Excel for the statements and the model, then Tableau and PowerPoint to present it.

> **Illustrative figures, for privacy.** Each project is modeled on a real business's size, sales channels and
> products. The numbers are not the business's actual results, which stay private.

| Project | What it shows |
|---|---|
| [Escentials LLC, FY2025](escentials-llc/) | Full financial statements with notes, budget vs actual, a three scenario forecast, KPIs, a SQLite transaction database, a CRM database, Tableau dashboards and a business review deck |
